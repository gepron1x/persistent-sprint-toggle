# Persistent Sprint Toggle

A mod which makes sprinting toggle persistent between game restarts.
This mod was inspired by
[Auto Sprint Fix](https://modrinth.com/mod/auto-sprint-fix)
It works well, however your sprint state still resets when you close your game.

Also take a note that this mod does not revert MC-263293 like Auto Sprint Fix does because as far as i checked it is not longer an issue for MC 26.3

Feel free to leave an issue if it's still the case, though!
